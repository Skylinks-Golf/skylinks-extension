# KOADOS.md (placeholder)

KoadOS was an agent-tooling framework built for this repo by a former contractor (Fryymann). Most of what it added here — named agent personas, a mandatory Linux boot/hydration script, and a strict "no raw file reads over 50 lines" rule — has been retired: it targeted an older, more constrained generation of coding agents and doesn't fit this Windows/Claude Code setup. The one piece that was still genuinely useful, using the `code-review-graph` MCP server for token-efficient, graph-based code navigation, has been moved into [AGENTS.md](AGENTS.md) under "Token-efficient exploration."
